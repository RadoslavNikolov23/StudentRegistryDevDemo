This project is a simple JavaScript-based student registry system developed as part of a DevOps course assignment. It demonstrates basic CRUD operations and integrates DevOps principles such as version control, automation, and continuous integration.

## Features
- Add, edit, and delete student records
- Store data locally using JSON
- Simple UI for interaction (if applicable)
- Modular code structure for easy maintenance

## Technologies Used
- JavaScript (ES6+)
- Node.js (optional, if backend is included)
- Git & GitHub for version control

## Setup Instructions
1. Clone the repository:
`git clone https://github.com/RadoslavNikolov23/StudentRegistryDevDemo/`
2. Open in Visual Studio Code
3. Run `npm install` to installs app dependencies from the package.json file.
4. Run `npm start` starts the app.

## DevOps Concepts Applied
- Git for source control
- GitHub for collaboration and issue tracking
- CI/CD pipeline setup (optional)
- Documentation and code quality practices
